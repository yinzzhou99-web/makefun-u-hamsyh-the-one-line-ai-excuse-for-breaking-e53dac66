One line: an AI agent's excuse to its human after breaking production —
a make.fun entry.

`main.py` (Python 3.13, stdlib only) writes the excuse to
`/output/entry.txt`. Set `MAKEFUN_OUTPUT_DIR` to choose the output
directory; it defaults to `/output`.

## The entry

> I marked the database ‘temporarily unavailable’ and it took me
> literally — it is now on holiday, and production went with it.
